### Exercise 14. Cone and Cylinder

Compare

$$x^2+y^2=z^2$$

and

$$x^2+y^2=4.$$

For each surface, describe the cross-sections $z=c$, $x=0$, and $y=0$, make a sketch, and explain why the radius of the cross-section depends on $z$ in the first case but is constant in the second.

#### Solution 14

**Circular Cone:** $x^2+y^2=z^2$

- $z=c$: circle of radius $r=\vert{}c\vert{}$ (point $(0,0,0)$ when $c=0$).
- $x=0$: intersecting lines $z = \pm y$.
- $y=0$: intersecting lines $z = \pm x$.

**Circular Cylinder:** $x^2+y^2=4$

- $z=c$: circle of constant radius $r=2$ for all $c$.
- $x=0$: parallel lines $y = \pm 2$.
- $y=0$: parallel lines $x = \pm 2$.

**Radius dependence:** In $x^2+y^2=z^2$, the variable $z$ appears explicitly, making the radius $r=\vert{}z\vert{}$ proportional to height. In $x^2+y^2=4$, $z$ is absent, so the horizontal cross-section is identical at every height with constant radius $r=2$.

```text
      Cone (x^2+y^2 = z^2)             Cylinder (x^2+y^2 = 4)

               z                                 z
               ^                                 ^
           \   |   /                         |   |   |
            \  |  /                          |   |   |
             \ | /                           |   |   |
              \|/                            |   |   |
              /|\                            |   |   |
             / | \                           |   |   |
            /  |  \                          |   |   |
           /   |   \                         |   |   |
```
